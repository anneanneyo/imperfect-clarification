# E003: подготовлен пилот с языковой моделью

20 октября 2026. Статус: **готова локальная инфраструктура; реальные API-вызовы не выполнены**. Это не новый исследовательский результат о качестве модели.

## Проверяемая задача

Один и тот же LLM-исполнитель выбирает рейс из одинакового каталога: без уточнений и после точного ответа, неоднозначного ответа либо «не знаю». Мы измеряем изменение награды конечного выбора. Так проверяется звено, отсутствующее в E001/E002: фактическое использование ответа языковой моделью, а не точным Bayesian-правилом.

Подготовлены 12 уникальных исходных записей, выбранных seed 20261020 из 89 подходящих eval-записей внешнего pinned репозитория. Для каждого: 5 примеров истории, новая задача и 8 вопросов × 3 ответа, плюс no-ask. Итого 300 запросов. Первый smoke-run — 25 запросов на одну задачу. Это знакомый development-датасет; не независимая агентная среда и не финальный test.

Намерение задаётся исходным reward vector только у evaluator и генератора ответов. В историю передаётся предпочтённый рейс, пересчитанный по reward vector. API получает историю, признаки рейсов и текст данного ответа, но не reward vector, правильный новый выбор или числовую награду. Описание исполнителя одинаково во всех условиях. Значения признаков нормированы; это промежуточный семиструктурированный интерфейс.

Ответы пока шаблонные, согласованы с истинным знаком предпочтения. Неоднозначный ответ оставляет два варианта, включая истинный. Пользователи не валидированы эмпирически, ответы не содержат фактических ошибок. Изначальная версия partial-шаблона фиксируется хешем; при её изменении нужен отдельный run.

## Ограничение вывода

Один ответ модели на ветку даёт наблюдаемую разницу, не точное ожидаемое уменьшение ошибки. No-ask общий для 24 ветвей одной задачи, поэтому ветви не независимы. Пока не обучаем селектор на этих же 12 задачах и не сообщаем максимум по веткам как достижимое качество метода. Сначала проверяем парсинг, правдоподобность интерфейса, единый исполнитель и наличие сигнала. До научного сравнения потребуются повторные исполнения, отдельные обучающие задачи и независимая проверка.

## Что уже проверено

Код [llm_executor_pilot.py](../experiments/llm_executor_pilot.py) использует стандартную библиотеку Python. Установка SDK не нужна. [Локальные тесты](../results/llm_executor_pilot/selftest.json): разбор результата; отклонение незавершённых ответов; ограничение числа вызовов; продолжение без повторения завершённых случаев; состав API-payload; расчёт награды; нулевой gain у постоянного ответчика; запрет смешивать модели в run; остановка после первой ошибки без автоматических повторов.

Тестовый ответчик всегда выбирает B, его результаты удалены вместе с временным каталогом и **не считаются модельными экспериментами**. Расходов и реальных API-вызовов не было. Код после ошибки сохраняет статус и останавливается, а не превращает ошибку API в плохое решение агента.

## Конкретный блокер

В окружении текущего агента не заданы OPENAI_API_KEY/OPENROUTER_API_KEY, не обнаружены ollama/llama-server или локальные библиотеки для выбранного пути inference. Отсутствие ключа проверяется по наличию переменной, значения не выводятся. Подготовленный транспорт использует OpenAI Responses API. Доступность модели для аккаунта ещё не проверена.

Нужно подключить исследовательский API-доступ в окружение проекта. Секретный ключ не надо присылать в чат или сохранять в репозитории. Поддержанный путь — переменная OPENAI_API_KEY; [официальный quickstart](https://developers.openai.com/api/docs/quickstart) описывает создание и использование ключа. Код, данные и тесты уже готовы; после подключения потребуется выбрать доступный model ID и зафиксировать его перед первым вызовом.

Пока model ID не выбран, долларовая оценка не установлена. Объём известен: 25 вызовов для smoke или 300 для полного пилота; максимум 512 выходных токенов на вызов. Все полные prompts вместе содержат 1 066 439 символов, плюс общие инструкции. Символы не равны токенам. Лимит вызовов/выходных токенов не является лимитом долларов. Стоимость рассчитывается по доступной модели перед реальным запуском; новые платные вызовы пока не выполняются.


# E020: факты с текстовым свидетельством

8 ноября 2026. До новых генераций. Контроль после E019 и целевого смыслового аудита 24 training-case / 44 расхождений. Один ассистент прочитал полные тексты: 39 неподдержанных модельных выводов, 1 поддержанный текстом вывод при неполной аннотации, 4 спорных расхождения. Разметка не независимая и не оценивает частоту во всём наборе. Primary E019 scores сохранены.

## Один фиксированный метод

Те же 24 development и 96 training-case, исходный текст без вопросов; E016 test не использовать. Модель и веса прежние. Вместо четырёх массивов требуем четыре объекта с массивом `values` и `evidence`: короткой точной цитатой (до 160 символов) или null. Неизвестное значение — весь домен и null. Модель получает только текст и одну закреплённую инструкцию. Никаких source evidence/profile/gold в messages.

Сохранять два результата каждого вывода: raw values и gated values. Во втором случае при сужении домена без непустой точной подстроки исходного пользовательского сообщения длиной <=160 вернуть полный домен для этого поля. При остальных условиях сохранить raw. Проверка цитаты **не** проверяет, действительно ли она подтверждает выбранный факт; это ограничение метода. Исходный JSON, цитаты и срабатывания gate сохранять.

Схема строгая: ровно четыре известных поля, в каждом ровно values/evidence. Значения — непустой список неповторяющихся допустимых строк; evidence — строка или null. Неверный JSON, лишние ключи, дубликаты, markdown = invalid всего вывода. Invalid даёт нулевое совпадение всех полей и остаётся в знаменателе. Runtime error также invalid. Недостающие генерации блокируют полный score. Без повторов плохих ответов.

## Метрики и решение

Отдельно для train/development: exact slot sets, known/unknown exact, all-four exact, route-set exact и single correct/wrong/uncertain при тех же 80 возможных сочетаниях. Сравнить E019 с raw E020 и gated E020. Не выдавать это за чистый эффект цитирования: меняются инструкция, формат и лимит вывода. Raw против gated использует одни и те же генерации и изолирует именно механическую фильтрацию цитат.

До исходов задать gate для перехода к проверке ответов: на 96 training-case ноль invalid, >=346/384 exact fields, >=192/202 known fields (95%), >=35/38 правильных однозначных маршрутов. Условие на known fields защищает от тривиального возврата «всё неизвестно». Это development threshold, не критерий научной значимости. При успехе следующий опыт проверяет partial/unknown ответы на вопрос; при неуспехе полный question replay не запускать, локализовать ошибку без перебора prompts до победы.

Greedy temperature0, seed20261108, max384 tokens, максимум120 prompts и1800 секунд. Закрепить все входы, код, модель, runtime lock и протокол до запуска. Временное прежнее окружение исчезло, новое восстановлено из сохранённого requirements.lock E013 в отдельном постоянном cache-каталоге; модельные хеши проверяются.

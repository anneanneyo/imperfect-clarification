# Предложение для следующего эксперимента

Сначала — углублённый разбор литературы, методов и уже проведённых опытов, затем обсуждение постановки с руководителем. Описанное ниже сравнение пока не согласовано и не запущено.

После разбора E027 можно проверить, насколько ошибки выбора связаны с формулировкой предпочтений и инструкцией модели.

Планируется сравнение 2×2 на тех же 12 диагностических задачах.

| | Исходная инструкция | Инструкция проверить каждое раскрытое условие |
|---|---|---|
| Косвенные предпочтения из UserBench | Сохранённый запуск E027 | Новый запуск |
| Явные формулировки тех же предпочтений | Новый запуск | Новый запуск |

Перед запуском нужно проверить смысловую эквивалентность формулировок и зафиксировать протокол, входы и бюджет. Сравнивать долю нарушенных раскрытых условий, допустимость конечного выбора и ранжирование вопросов. Все новые ответы сохранять с первой попытки.

Это диагностика на знакомых данных. Для проверки основной гипотезы затем нужны распределение возможных ответов, сильные EVSI/IG-сравнения, direct value и факторизованная модель при одинаковых данных и вычислениях. Проверку переноса проводить на новых задачах с контролем повторяющихся шаблонов.

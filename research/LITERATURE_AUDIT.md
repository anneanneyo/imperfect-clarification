## Главный вывод

Исходный PLAN.md недостаточен для заявления новизны. Прогноз ответа, оценка полезности вопроса и работа с несовершенной обратной связью уже имеют прямых предшественников. Проверяемый кандидат на вклад — обучение и адаптация при изменении распределения ответов с измерением конечных потерь. Это гипотеза о возможном вкладе, а не установленный пробел литературы.

## Что проверять дальше

1. В Dong, ClarifyMT, Kobalczyk и Rao: как оценивается ответ, что обучается, есть ли перенос между пользователями/режимами ответа и адаптация на малом числе примеров.
2. Старшая литература: active preference elicitation, Bayesian experimental design, decision-theoretic dialogue, response-model misspecification. Поиск за пределами LLM обязателен.
3. Для внешней среды: лицензия, доступные данные, установка, точный checker конечного решения, возможность переиграть один эпизод с разными ответами, стоимость запуска.
4. Зафиксировать версии текстов и commit кода до воспроизведения. Текущее открытие страницы репозитория не считается аудитом кода или подтверждением воспроизводимости.

Примеры поисковых запросов: `LLM clarification imperfect user responses expected value information response model`; `language models value of information clarification`; `decision theoretic clarification user response model active preference elicitation`; точные названия работ из плана.

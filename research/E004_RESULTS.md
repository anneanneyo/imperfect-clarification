# E004 — что именно мешает двигаться к статье

20 октября 2026. Закончен математический и вычислительный разбор E002. Это анализ после просмотра предыдущих результатов, не независимая проверка гипотезы. Никаких моделей не устанавливали, API не вызывали.

## Основное решение

**Не увеличивать модель и не запускать E003 сейчас.** У прежней постановки почти не осталось пространства для улучшения выбора вопроса. Более сложный, но всё ещё искусственный механизм ответа создаёт небольшой разрыв. Сначала требуется определить, по каким наблюдениям мы будем обучать и проверять ценность вопроса. Тема остаётся прежней: уточнения при неполных ответах ради конечного решения.

Новая рабочая гипотеза, пока без подтверждённой новизны: небольшая разметка конечных исходов может быть полезнее дополнительных неразмеченных ответов для оценки вопросов, когда форма неполного ответа зависит от скрытого намерения. «Форма ответа зависит от намерения» и «нужно учитывать отказы» сами по себе не новые идеи. Подробное сопоставление — [литературное дополнение](LITERATURE_UPDATE_2026-10-20.md).

## 1. Почему E002 почти решается простой поправкой

Пусть θ — скрытые предпочтения, a — конечный выбор, u(θ,a) — награда. Для фиксированной задачи известен prior p(θ). Ценность канала ответов K для оптимального исполнителя:

\[
V(K)=\sum_y\max_a\sum_\theta p(\theta)K(y\mid\theta)u(\theta,a)
-\max_a\sum_\theta p(\theta)u(\theta,a).
\]

В E002 тип ответа (точный, неоднозначный, «не знаю») выбирается с вероятностями e, b, 1−e−b, не зависящими от θ при фиксированных задаче и вопросе. Тип виден исполнителю: алфавиты трёх ветвей не пересекаются. Поэтому множитель вероятности можно вынести из каждого max, и получается **точное** равенство:

\[
V=eV_{\mathrm{exact}}+bV_{\mathrm{partial}}.
\]

Ветвь «не знаю» не меняет prior и даёт нулевую выгоду. Это не общая линейность ценности по любой смеси каналов: существенны наблюдаемый тип ветви и независимость её выбора от θ. Если тип скрыт, равенство в общем случае неверно.

Независимый пересчёт исходных каталогов и fit-профилей подтвердил равенство на **6496 парах задача–вопрос**: 4616 fit, 1160 validation, 720 development holdout. Максимальное численное расхождение < 10⁻¹⁵.

При V_exact > 0 эффективная поправка равна e + b × V_partial / V_exact. На development holdout медиана V_partial / V_exact = 0.4624, межквартильный диапазон 0.3609–0.4952. Это помогает объяснить успех поправки по типу вопроса, но само по себе не гарантирует постоянный коэффициент: важны также изменения e, b и расстояние между лучшими вопросами.

| Проверка на 90 development-задачах | Результат |
|---|---:|
| Простой метод совпадает с oracle по выбранному вопросу | 84 / 90 |
| Средняя потеря simple | 0.419668776 |
| Средняя потеря oracle | 0.419503327 |
| Всё доступное улучшение simple → oracle | 0.000165449 |
| Максимальный разрыв на отдельном каталоге | 0.010465771 |
| Средняя абсолютная ошибка оценки ценности по всем вопросам | 0.002071585 |

Иными словами, улучшение MSE оценивателя может почти не менять решение. Если максимальная ошибка оценок в задаче ε, а истинный отрыв лучшего вопроса от второго больше 2ε, выбор гарантированно сохраняется: оценка лучшего не ниже V₁−ε, любого другого не выше V₂+ε. Этот достаточный критерий выполнен в 46 из 90 задач. Это диагностический сертификат с доступом к истинным значениям, не доступный агенту online stopping rule.

Нельзя утверждать, что задача «полностью решена», но среднее пространство для улучшения в **этом** протоколе слишком мало, чтобы оправдывать большую архитектуру.

## 2. Ответ зависит от предпочтения: контролируемая проверка

Сохранили каталоги, prior, вопросы и средние вероятности точного/частичного ответа/отказа. Изменили только индивидуальную вероятность точного ответа:

e(θ)=e+λ min(e,1−e−b) z(θ), где z — центрированная абсолютная величина соответствующего коэффициента предпочтения, нормированная в [−1,1]. Поэтому E[z]=0 и E[e(θ)]=e. Частичная ветвь остаётся с вероятностью b. Все вероятности проверены на нормировку и допустимость.

Отрицательное λ означает, что сильное предпочтение реже выражается точно; положительное — чаще. Это заранее указанный искусственный stress test, не эмпирическая модель людей. Средние частоты **типов** ответов одинаковы; частоты конкретных знаков/пар могут меняться, поэтому данный stress test не является доказательством неидентифицируемости.

Сравнили oracle с системой, которая знает прежние средние rates, но игнорирует их зависимость от θ. Это сильный аналитический контроль, не новый обученный конкурент. Разделили ошибки выбора вопроса и интерпретации ответа:

| λ | Другой вопрос, из 90 | Потеря от выбора вопроса при правильном исполнителе | Дополнительная потеря неправильного исполнителя на выбранном вопросе | Общий разрыв |
|---:|---:|---:|---:|---:|
| −1 | 14 | 0.000914 | 0.000886 | 0.001800 |
| −0.5 | 7 | 0.000262 | 0.000241 | 0.000502 |
| 0 | 0 | 0 | ≈0 | ≈0 |
| 0.5 | 10 | 0.000466 | 0.000267 | 0.000733 |
| 1 | 15 | 0.001315 | 0.001265 | 0.002580 |

В выбранных вопросах отрицательной ожидаемой выгоды не возникло. Максимальный из проверенных средних разрывов 0.00258 — около 1.3% от oracle-выгоды 0.20231 в соответствующем режиме. Не следует выдавать изменение числа вопросов за большой прирост качества. **Простое усложнение симулятора всё ещё не обосновало сильную исследовательскую ставку.**

## 3. Какие данные действительно позволяют узнать пользу

Построен и точно проверен пример с тремя равновероятными намерениями A, B, C. Ответ — правдивая пара: «A или B», «B или C», «A или C». Истинное намерение всегда содержится в ответе.

| Намерение | Мир 1: AB / BC / AC | Мир 2: AB / BC / AC |
|---|---|---|
| A | 0.8 / 0 / 0.2 | 0.2 / 0 / 0.8 |
| B | 0.2 / 0.8 / 0 | 0.8 / 0.2 / 0 |
| C | 0 / 0.2 / 0.8 | 0 / 0.8 / 0.2 |

В обоих мирах каждый ответ встречается ровно в 1/3 случаев. Исполнитель, настроенный на мир 1, выбирает A после AB, B после BC, C после AC. Тогда:

- без вопроса вероятность успеха 1/3;
- после вопроса в мире 1 — 0.8;
- после того же вопроса в мире 2 — 0.2.

У фиксированного исполнителя ценность вопроса соответственно +0.4667 и −0.1333. Это не отрицательная Bayesian value of information при правильной модели: правильный исполнитель во втором мире тоже получил бы 0.8. Случайный выбор внутри названной пары получил бы 0.5 в обоих мирах. Следовательно, пример также не доказывает необходимость сложного обучаемого метода: есть простой осторожный конкурент.

**Доказательство ограничения данных.** Если наблюдаем только один ответ на этот вопрос от каждого независимого пользователя, без его истинного намерения или результата решения, распределение любого объёма таких журналов в двух мирах совпадает. Никакой алгоритм по ним не может гарантированно определить, какая из двух ценностей фиксированного исполнителя верна. Это утверждение не относится к журналам с правильными исходами, дополнительными вопросами к тому же человеку или информативным контекстом. И это иллюстрация известной проблемы неполных наблюдений, не заявка на новую теорему.

Практический вывод: частота отказов и качество предсказания текста ответа сами по себе не валидируют оценку конечной пользы. В протоколе нужны наблюдаемые исходы, раскрытые намерения на подвыборке либо явно обоснованные ограничения на механизм ответа.

## 4. Обнаружена граница применимости нашего ограничения предсказаний

В E002 прогноз ограничивался диапазоном [0,V_exact_sign]. Там это корректно: несовершенный ответ получается случайным огрублением известного знака коэффициента. За пределами этой модели ограничение переносить нельзя.

Контрпример: четыре равновероятных положительных коэффициента 0.1, 0.2, 2, 3. Награда первого действия всегда 0.5, второго равна коэффициенту. Точный знак всегда «плюс» и имеет ценность 0. Если точный ответ даётся при коэффициентах 2 и 3, а «не знаю» при 0.1 и 0.2, форма ответа дополнительно сообщает величину. Ценность такого канала 0.175. Он не является случайным огрублением одного только знака. Верхняя граница по раскрытию **всего** скрытого состояния остаётся верной.

Для фиксированного ошибающегося исполнителя ценность может быть и отрицательной. В будущем ограничивать его оценку снизу нулём также нельзя без специальных предположений. E002 не переписываем задним числом: его результаты корректны в заявленном классе каналов.

## 5. Конкретный следующий протокол

Следующий блок — **E005: обучение на ограниченной наблюдаемой обратной связи**, сначала без LLM. В отличие от E002, обучающий алгоритм больше не получает точное интегрированное значение каждого вопроса.

Наблюдение: контекст x, случайно выбранный q (включая no-ask), вероятность его выбора μ(q|x), фактический ответ y, конечный выбор фиксированного исполнителя a, наблюдаемая награда r. Истинное намерение и все контрфактические награды доступны только внешнему checker при оценке, не предиктору. Награда после решения должна существовать в будущей реальной среде; синтетический checker не решает автоматически эту проблему.

При рандомизации, покрытии вариантов и фиксированном исполнителе можно оценивать среднюю награду стратегий, включая разницу с no-ask. Не требуется наблюдать индивидуальный контрфактический результат того же человека. Предсказание для каждого нового контекста дополнительно требует обобщения; рандомизация этого не гарантирует.

Обязательные конкуренты: simple calibration, прямая регрессия награды, факторизованная модель ответа/полезности при одинаковой доступной разметке, известные IPS/DR-оценки для оценки политик, oracle только как ориентир. Поиск новизны не подменять применением известного DR-метода.

Нельзя выбирать итоговый тест, силу зависимости или стоимость вопроса ради выигрыша. До запуска фиксировать budgets, splits, seed, правила no-ask, диапазон наград и критерий practically useful gain. Сначала feasibility-аудит возможных внешних сред: есть ли checker, неполные ответы, лицензия, доступная стоимость и возможность рандомизации. Независимый агентный тест остаётся необходимым этапом будущей статьи.

**Условия отказа:** если после честной обратной связи простые методы снова исчерпывают почти весь выигрыш; если эффект есть только в придуманном механизме; если нет внешнего способа проверить качество решения — не масштабировать обучение и пересмотреть конкретную гипотезу.

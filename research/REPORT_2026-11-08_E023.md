# Что продвинулось: E023 и проверка следующей среды

**Мы проверили, подходит ли нынешний набор данных для главного вопроса проекта. Ответ: для проверки вычислений подходит, для большого исследования неполных ответов пока слабоват.** Тему не меняем; меняем основание для следующего эксперимента.

Взяли 96 новых групп ситуаций, заранее исключив уже использованные. Для каждой посчитали последствия пяти вопросов и варианта без уточнения. Всего 1698 ветвей. Отдельная программа пересчитала всё и подтвердила результат. Ещё 217 групп оставлены без оценки исходов.

Без вопросов точность математического исполнителя — 67,5%; один и тот же вопрос о продукте — 77,1%. Если заранее знать результаты всех вопросов, можно получить 91,7%. Последняя цифра — диагностический ориентир с недоступным агенту знанием, не качество нашей модели.

Главное уточнение: большой запас выбора вопросов ещё не означает большой запас **учёта неполноты ответа**. Когда убрали влияние случайного выбора между равноценными вопросами, строгая смена лучшего вопроса нашлась только в 1 из 96 групп, с общим разрывом 0,52 процентного пункта. Заранее заданный критерий продолжения — хотя бы 8 групп и 1 п.п. — не выполнен. На этой выборке не стоит разворачивать большое обучение ради нашей основной гипотезы.

Проверили и понятность разметки: сначала разобрали 36 текстов без эталонных полей, потом сравнили. Совпали все 144 значения-множества. Это небольшая проверка одним ассистентом, а не независимая человеческая оценка.

Дальше разобрали **UserBench** — внешнюю среду выбора туристических вариантов по предпочтениям. В 12 ручных проверках кода обнаружили различие остановки между двумя интерфейсами. Отдельный искусственный ответ «не знаю» показал, что среда может начислить награду за выявленное предпочтение без проверки содержания ответа. Поэтому для нашего эксперимента будем отдельно считать качество окончательного выбора и явно определим остановку. Реальных задач UserBench и новых языковых генераций в этом блоке ещё не было.

Код, результаты и отчёты собраны в ветке `codex/research-e023` репозитория `anneanneyo/imperfect-clarification`. Имя куратора сохранено по актуальному README GitHub. Небольшие обученные оценщики сохранены в результатах. Веса больших языковых моделей и окружения хранятся отдельно. [Ветка на GitHub](https://github.com/anneanneyo/imperfect-clarification/tree/codex/research-e023).

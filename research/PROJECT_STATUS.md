# Ход работы

Обновлено 9 ноября 2026.

## Задача

Проверить, помогает ли раздельное моделирование цели пользователя и возможного ответа выбирать уточняющие вопросы при изменении полноты ответов. Основное сравнение — с прямым предсказанием пользы, information gain и Bayesian EVSI при одинаковом бюджете вопросов.

## Выполнено

| Этап | Результат |
|---|---|
| Проверка UserBench | Разобраны 12 задач, 48 отдельных выборов, 96 предпочтений и 864 варианта |
| Проверка предпочтений | Составлены предварительные правила, отдельно учтены неизвестные значения |
| Запуск Qwen3-4B | Сохранены 192 ответа при четырёх режимах раскрытия предпочтений |
| Пересчёт | Совпали 576 оценок выбора, 576 результатов вопросов и 36 ранжирований |
| Анализ ошибок | Разобраны все 14 нарушений предпочтений при полном ответе |

По исходным меткам Qwen выбрала допустимый вариант в 10/48 случаев без дополнительных сведений и в 31/48 при раскрытии обоих предпочтений для всех частей поездки. По нашим правилам оба условия подтверждены в 24/48 случаев полного ответа, в 14 есть нарушение, в 10 сведений недостаточно.

В 9/12 задач при полном ответе несколько вопросов делят максимум по исходным меткам. Строгую смену единственного лучшего вопроса по проверяемым предпочтениям у Qwen пока не нашли.

## Ограничения

Выборка небольшая и уже использована при разработке. В задачах повторяются шаблоны. Исходная разметка содержит спорные варианты, а наши семантические правила составлены с помощью ИИ и требуют независимой проверки человеком. Частичные ответы заданы искусственно. Вероятности ответов реальных пользователей пока неизвестны.

Основное сравнение обучаемых методов и проверка переноса на независимых данных ещё предстоят. Новизна предполагаемого метода требует уточнения относительно близких работ.

# E002 — обучен первый оцениватель ценности вопроса

19 октября 2026. Выполнено по [протоколу](E002_PROTOCOL.md), без подбора признаков после просмотра holdout.

## Что реализовано

Вместо только точного ответа/отказа добавлен формальный неоднозначный ответ: например, «предпочтение отрицательное или нейтральное». Он оставляет несколько возможных состояний. Исполнитель обновляет вероятности по фактической модели такого ответа; неоднозначность не приравнивается автоматически к отсутствию информации. Это структурированная частичная информация, не понимание свободного текста.

Обучен direct ridge estimator: регуляризованная линейная модель предсказывает ожидаемое уменьшение ошибки конечного выбора для каждого вопроса. Ей доступны характеристики каталога, тип вопроса и аналитическая ценность идеального ответа при общем известном prior. Истинные вероятности несовершенных ответов и скрытый профиль на вход предиктору не передаются. Таким образом, это структурный обучаемый baseline, а не end-to-end модель и не проверка превосходства факторизации H3.

Метки вычислены точным симулятором, который знает модель ответа. Такое обучение использует привилегированную синтетическую разметку; оно ещё не решает проблему получения реалистичных обучающих данных.

## Разбиение

577 fit-каталогов (4616 пар «задача–вопрос»), 145 validation (1160 пар), 90 development holdout (720 пар). Популяция из 577 fit-профилей известна всем исполнителям; реальные предпочтения holdout не используются. Один каталог — последний раунд внешней записи, поэтому E002 нельзя напрямую численно сравнивать с E001a, где брали шестой раунд и другой prior.

Fit/validation разделены по профилям. Пересечения каталогов, включая перестановки вариантов, проверены; совпадений не найдено. Внешний eval уже анализировался ранее и не считается новым нетронутым финальным тестом. Alpha=10 выбрана только по конечным потерям validation из пяти заранее заданных вариантов.

## Результат

Средний ожидаемый regret, меньше лучше. Основной режим: один вопрос, цена нулевая.

| Метод | Потеря |
|---|---:|
| Без вопросов | 0.598205 |
| Случайный вопрос | 0.502505 |
| Выбор с ожиданием идеального ответа | 0.424751 |
| Простая обученная поправка по типу вопроса | 0.419669 |
| Обученный ridge-оцениватель | 0.419635 |
| Точный ориентир с известной моделью ответа | 0.419503 |

Простая поправка — один коэффициент на тип вопроса, умноженный на ценность идеального ответа. Она получает те же fit-метки. Это сильный конкурент, а не намеренно слабый baseline.

Разница ridge минус ideal: −0.005117, парный bootstrap 95% [−0.007879; −0.002715]. Разница ridge минус simple: всего −0.000034, интервал [−0.000103; 0]. Ridge и simple выбирают разные вопросы лишь в 2 из 90 каталогов. **Убедительного преимущества усложнённого оценивателя над простой поправкой нет.** Уменьшение MSE предсказания пользы тоже само по себе не является достаточным результатом для решения задачи.

Интервалы по каталогам условны на фиксированной синтетической популяции и одном разбиении; они не измеряют вариативность человеческих ответов и повторного обучения. Это разведочная оценка, без коррекции множественных сравнений.

## Проверка частичной информации

Контроль с известной моделью, который выбрасывает неоднозначные ответы, получает потерю 0.458844 против 0.419503 при их корректном использовании. Это разница между двумя идеализированными исполнителями в искусственной среде, а не эффект обучения ridge и не новое открытие о пользе частичной информации.

При цене вопроса .02 все методы-селекторы продолжают спрашивать, потери возрастают на .02. Порог остановки этим набором содержательно не проверен.

## Решение

Появился минимальный работающий обучаемый оцениватель, соответствующий исходной тематике. Но простая модель ответа и известный prior делают задачу почти решённой калибровкой. Не увеличивать размер модели на этом основании. Следующий необходимый уровень — спецификация доступной обратной связи для содержательных текстовых ответов, фиксированный реальный исполнитель и независимая агентная среда. Адаптация к смене популяции остаётся дополнительной веткой; основной вопрос — ценность несовершенного уточнения для конечного решения.

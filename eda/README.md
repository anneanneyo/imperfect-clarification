Research-трек с NLP-данными: баланс, качество, выбросы, baseline, аугментации, выводы; дополнительно — статистики, пропуски, связи признаков и pairplot. Практическая ценность вынесена в PDF.

Повторение из корня репозитория, в отдельном Python-окружении:

    python -m pip install -r eda/requirements.txt
    python eda/build_eda.py

Notebook использует сохранённые данные и результаты; модель заново не запускается, внешние наборы не скачиваются. Графики встроены в notebook. Источники и версии указаны внутри, исходная разметка не переписывается.

Архив предыдущего анализа: outputs/checkpoint2_2026-10-27. Он относится к другой синтетической постановке и не смешан с текущим EDA. Исследовательские протоколы и исходные результаты сохранены в research/ и results/; удалять их ради сокращения списка файлов не требуется.

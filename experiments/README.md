# Код экспериментов

Для текущего чекпойнта основной файл — [EDA.ipynb](../EDA.ipynb). Его сборка находится в [eda/build_eda.py](../eda/build_eda.py).

## Текущий пилот UserBench

| Файл | Назначение |
|---|---|
| [executors_e027.py](executors_e027.py) | Эвристика, обработка выбора и метрики |
| [prepare_executor_e027.py](prepare_executor_e027.py) | Подготовка входов модели |
| [run_executor_e027.py](run_executor_e027.py) | Запуск локальной Qwen |
| [analyze_executor_e027.py](analyze_executor_e027.py) | Расчёт оценок и ранжирований |
| [audit_e027.py](audit_e027.py) | Отдельный пересчёт сохранённых результатов |

Для проверки опубликованных чисел достаточно двух команд из корня репозитория.

```bash
python3 experiments/analyze_executor_e027.py --verify
python3 experiments/audit_e027.py
```

Python 3.9+, стандартная библиотека. Поведение второго скрипта описано в [инструкции](../REPRODUCE.md).

## Предыдущие этапы

Суффиксы e025 и e026 относятся к подготовке UserBench и правилам проверки предпочтений. Остальные скрипты сохраняют реализации предыдущих опытов. Их данные, предпосылки и зависимости указаны в соответствующих [протоколах](../research/README.md). Номера этапов позволяют связать код с сохранёнными результатами.

# Проверка сохранённых результатов

Рабочая ветка: `codex/research-e023`. Python 3.10+ достаточен для проверок E023/E024; новых модельных генераций они не требуют. Старые эксперименты имеют собственные зависимости и исторические абсолютные пути. Их протоколы, скрипты и исходные результаты сохранены без переписывания.

## E023

```bash
python3 experiments/reproduce_e023.py
```

Команда проверяет хеши, находит или скачивает только закреплённый banking train Lavoir и выполняет независимый проверяющий код E023. Официальные test-файлы не нужны. Для переноса на другой компьютер заменяются только два обращения к историческому пути исходного train-файла в исполняемом AST; файл проверяющего кода и замороженные манифесты не меняются. Выборка, правила, веса, подсчёты и аудит пересчитываются полностью.

## E024

Сохранённые результаты: `results/userbench_contract_e024/`. Их входы и код закреплены в `manifest.json`. Скрипт по умолчанию не перезаписывает готовый результат. Для повторения скопируйте `experiments/userbench_contract_e024.py` и `research/E024_PROTOCOL.md` в пустую временную структуру с теми же каталогами и запустите оттуда. Он скачает три файла UserBench по закреплённому commit, проверит Git blob SHA и выполнит 12 ручных траекторий и инъекцию отказа генератора. Модельные/API вызовы и benchmark-данные не используются.

## Архивные таблицы

Две большие построчные CSV ранних синтетических опытов хранятся в Git в gzip-формате. Чтобы восстановить исходные байты по старым путям:

```bash
python3 experiments/restore_large_results.py
```

Хеши проверяются до записи. Остальные файлы результатов доступны непосредственно. Исторические ссылки на личные временные каталоги в замороженных отчётах могут не работать на другом компьютере; это не команды установки и не подтверждение наличия этих каталогов.

Происхождение внешних данных: [THIRD_PARTY.md](THIRD_PARTY.md). Веса больших языковых моделей, окружения, ключи доступа, личные учебные работы и резюме в набор проекта не входят. Небольшие обученные матрицы оценщиков сохранены в `results/`.
